# malikstefan.com

A public build log for a 20-week project. The site itself is the first thing built.

Live at [malikstefan.com](https://malikstefan.com)

## Running locally
```
git clone git@github.com:likiyadiig/malikstefan-site.git
cd malikstefan-site
npm install
npm run dev
```

Opens at `localhost:4321`.

## Build
```
npm run build
```
Output goes to `dist/`.

## Deployment

Cloudflare Pages, building from `main` on every push.
